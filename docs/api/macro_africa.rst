Macro Africa Module
===================

Economic indicators for African countries.

.. automodule:: actuneo.macro_africa

.. autofunction:: actuneo.macro_africa.world_bank_indicator

.. autofunction:: actuneo.macro_africa.macro_data

``INDICATORS`` maps short names (``inflation``, ``gdp_growth``,
``gdp_per_capita``, ``exchange_rate``, ``lending_rate``, ``deposit_rate``,
``real_interest_rate``, ``population``, ``life_expectancy``) to World Bank
codes. ``COUNTRIES`` maps country names to ISO codes.

Planned Features
----------------

* National sources (statistics offices and central banks)
* Monthly series and yield curves
